# Design implementation specification scope

Audience: product designer.
Purpose: define the purpose and boundary of the missing designer handoff without yet making visual decisions.
Authority: scope proposal derived from the artifact charter and approved PRD.

The designer specification must translate the approved low-fidelity buyer and information flow into a high-fidelity interface. It should decide and document visual hierarchy, component and interaction patterns, responsive behavior, accessibility, motion, content presentation, and visual assets.

It must consume the approved PRD and low-fidelity model. It must not redefine the buyer job, add a workflow stage, change approval authority, prescribe software architecture, or define AI prompts and model behavior.

Its completion evidence should include a high-fidelity prototype or implemented design reference, a design-token and component rationale, responsive states, accessibility checks, and a review against the low-fidelity flow.
