# Aera documentation

> Audience: all reviewers.
> Purpose: route readers to the smallest useful evidence set.
> Authority: navigation only; linked documents declare their own role.

## Document authority

- Product contract: current user-facing behavior.
- Implementation index and verification matrix: derived traceability and evidence.
- AI brief and walkthrough: constrained review and demo guidance.
- Decision ledger: canonical decision authority and historical lineage.
